2. How to Contribute
Reporting Bugs
Before opening an issue, please search existing issues to see if it has already been reported.
When filing a bug report, include:
 * A clear, descriptive title.
 * Steps to reproduce the issue.
 * Expected vs. actual behavior.
 * Your operating system and environment details.
Suggesting Features
Feature requests are always welcome! Please open an issue to discuss proposed features before writing major amounts of code, so we can ensure it aligns with the project's roadmap.
Submitting Code Changes
 * Fork the Repository: Create your own fork on GitHub/GitLab.
 * Create a Feature Branch: git checkout -b feature/your-feature-name
 * Write Clean Code:
   * Keep changes focused; avoid bundling unrelated changes into a single PR.
   * Write or update tests where appropriate.
   * Follow the existing code style guidelines.
 * Commit Your Changes: Use clear, descriptive commit messages.
 * Open a Pull Request: Submit your PR against the main (or develop) branch of the primary repository.

3. Code Review Process
 * Maintainers will review your pull request as soon as possible.
 * Address any requested changes or discussion points in your branch.
 * Once approved and tests pass, a maintainer will merge your PR.
Thank you for helping keep software free and open!
